    2.0 m (~6'-7") is a safe default — clears typical furniture while keeping door headers. Increase if furniture is still showing up in the ortho.

    3. Trace ceiling zones

    1. Click vertices, then click the first one (or press Enter) to close.
    2. Trace the line between two ceilings. End on the room outline (chord), or click the first vertex to close (island ring).
    3. Hatched negative space — ceiling regions stop at the boundary.

    How tracing works: trace each visible ceiling boundary once as an interface — adjacent ceilings share that edge. Click Define ceilings below to turn the interfaces into tinted faces. Then pick which face is the height datum (Main) in the Regions panel.

    Tools

    Click a vertex to drag. Press Delete over a vertex to remove it.

    4. Define ceilings

    Polygonises the room outline + every interface into N tiled ceiling faces. The largest is the default Main; pick another via the Regions panel's Main radio if needed.

    5. Export

    Coloured masks, relative-height tags on each polygon, and dimensioned room outline.
